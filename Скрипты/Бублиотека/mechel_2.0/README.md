# Mechel — библиотека частых методов и API-клиента

## Версии
- oscript: 2.1.0+
- vanessa-runner: 2.6 (тесты рассчитаны на эту версию)

## Назначение
- Утилиты для API (парсинг кодов, строк баз, статусов)
- Логика пайплайна (ветки Git, изменённые файлы, запуск Предприятия)
- Транспорт к API (блокировки, сеансы, восстановление, обслуживание)

## Установка
Подключить через lib.config или вручную добавить пути к `src/Модули` и `src/Классы`.

## Тесты
```bash
oscript tests\ТестыБиблиотеки.os
```

## Примеры

### Инициализация клиента
```oscript
Клиент = Новый АПИКлиент("https://ukm-web/ad/IT/IT_TechAdmin/hs/");
Клиент.УстановитьТокен("erp-restore-api-token");
```

### Блокировка базы
```oscript
ПараметрыБлокировки = Новый Структура;
ПараметрыБлокировки.Вставить("База", "ERP_KGOK_RELEASE_DRAFT");
ПараметрыБлокировки.Вставить("Причина", "Jenkins: восстановление из архива");
Клиент.ЗаблокироватьБазу(ПараметрыБлокировки);
```

### Опрос статуса восстановления
```oscript
Статус = Клиент.ОжидатьСтатусВосстановления(ГУИДЗаявки, 7200, 60); // таймаут 2 часа, интервал 60 сек
```
