erp_library

Набор общих pipeline-методов для сборки артефактов 1С через shared library Jenkins.

Основные методы

1. buildCfFromXmlAndPublish(Map args)
   Сборка основной конфигурации из XML-выгрузки через автономный сервер 1С.
   Метод:
   - берет XML из WORKSPACE\src\cf
   - создает локальную файловую ИБ
   - импортирует конфигурацию через ibcmd
   - сохраняет 1Cv8.cf
   - публикует файл в каталог артефактов ветки
   - удаляет временные каталоги и локальный cf-файл

   Обязательные параметры:
   - branchName : имя ветки, например origin/update/2.5.22.155

   Результат:
   - возвращает полный путь к опубликованному файлу 1Cv8.cf

2. buildCfeFromXmlAndPublish(Map args)
   Сборка расширения Mechel из XML-выгрузки через автономный сервер 1С
   с выгрузкой результата конфигуратором.
   Метод:
   - берет XML из WORKSPACE\src\cfe\Mechel
   - создает новую локальную файловую ИБ
   - создает расширение Mechel через ibcmd
   - импортирует XML расширения в это расширение
   - выгружает Mechel.cfe через конфигуратор (/DumpCfg -Extension)
   - публикует файл в каталог артефактов ветки
   - удаляет временные каталоги и локальный cfe-файл

   Обязательные параметры:
   - branchName : имя ветки, например origin/update/2.5.22.155

   Результат:
   - возвращает полный путь к опубликованному файлу Mechel.cfe

Правила работы

- Каталог артефактов строится из branchName.
- Символ "/" в имени ветки преобразуется в вложенные каталоги.
- Для поиска платформы выбирается самая новая версия из C:\Program Files\1cv8\<version>\bin.
- Для CF используется ibcmd.
- Для CFE используется ibcmd для загрузки XML и 1cv8.exe DESIGNER для выгрузки файла расширения.
- Временные локальные каталоги и файлы очищаются в finally-блоке.

Примеры использования

def cfPath = erp_library.buildCfFromXmlAndPublish(
    branchName: branchNameRaw
)

def cfePath = erp_library.buildCfeFromXmlAndPublish(
    branchName: branchNameRaw
)

Типовой результат публикации

\\ukm-sapp108\artifacts\origin\update\2.5.22.155\1Cv8.cf
\\ukm-sapp108\artifacts\origin\update\2.5.22.155\Mechel.cfe
