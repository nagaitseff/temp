# Новые OneScript-скрипты

Производственные скрипты добавляются здесь по одному после проверки API-клиента.
Общая библиотека — `../Библиотека/mechel`; токен поступает из Jenkins credentials
через переменную среды `MECHEL_API_TOKEN`.

[Примеры/ПроверитьАПИ.os](Примеры/ПроверитьАПИ.os) — первый пример:
только чтение списка агентов и, при наличии `MECHEL_TEST_INFOBASE`, параметров
блокировки указанной ИБ. Саму блокировку он не изменяет.

Пример запуска из PowerShell:

```powershell
$env:MECHEL_API_URL = 'https://ukm-web/ad/IT/IT_TechAdmin/hs/'
$env:MECHEL_TEST_INFOBASE = 'СЕРВЕР:ПОРТ|ТЕСТОВАЯ_БАЗА'
# MECHEL_API_TOKEN задаётся Jenkins через withCredentials.
oscript '.\Примеры\ПроверитьАПИ.os'
```

Ближайшие производственные скрипты: восстановление и ожидание статуса, блокировка
и завершение сеансов, загрузка CF/CFE, дополнительное расширение по UNC-пути,
монопольное обновление, настройка универсального пользователя.
Имена полей сеансов и доступ к ИБ после восстановления уточняются на рабочем стенде.
