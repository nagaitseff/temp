# Новые OneScript-скрипты

Производственные скрипты добавляются здесь по одному после проверки API-клиента.
Примеры используют вход `../Библиотека/mechel/api`. Jenkins передаёт значение
выбранного Secret Text через `MECHEL_API_TOKEN`.

[ПроверитьАПИ.os](Примеры/ПроверитьАПИ.os) читает список агентов. При заданной
`MECHEL_TEST_INFOBASE` он также читает параметры блокировки этой ИБ.
Для проверки обоих запросов на агенте используйте [Jenkinsfile](../Пайплайны/ПроверитьАПИ.Jenkinsfile).
Для запуска из `C:\OneScript_2\api` возьмите
[версию для установленной библиотеки](Примеры/НаАгенте/ПроверитьАПИ.os).

Пример запуска из PowerShell:

```powershell
$env:MECHEL_API_URL = 'https://ukm-web/ad/IT/IT_TechAdmin/hs/'
$env:MECHEL_TEST_INFOBASE = 'СЕРВЕР:ПОРТ|ТЕСТОВАЯ_БАЗА'
# MECHEL_API_TOKEN задаётся Jenkins через withCredentials.
oscript '.\Примеры\ПроверитьАПИ.os'
```

Для монопольного обновления ждём контракт функции, которая завершает сеансы
и соединения, и подтверждение доступа к восстановленной ИБ.
