# Новые Jenkins-пайплайны

Здесь будет универсальный пайплайн после проверки новой библиотеки на рабочем
оркестраторе и последовательной разработки скриптов.

Планируемые параметры:

- База-источник и база-приёмник копии.
- Необязательная Git-ветка для сборки основной конфигурации и расширения Mechel.
- Имя дополнительного расширения и сетевой путь `\\сервер\ресурс\файл.cfe`.
- Параметры монопольного обновления и настройки универсального пользователя.
- Jenkins credentials для API-токена и других нужных учётных данных.
- Уровень логирования и выбор дополнительных проверок.

Пайплайн ещё не реализован. Рабочие старые джобы используются как эталон поведения.
Исходные промпты не являются принятым техническим заданием.
