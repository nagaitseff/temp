# Новые Jenkins-пайплайны

[ПроверитьАПИ.Jenkinsfile](ПроверитьАПИ.Jenkinsfile) читает список агентов и
параметры блокировки тестовой ИБ. При запуске задайте `MECHEL_TEST_INFOBASE`
и выберите Secret Text в параметре `TOKEN`. По умолчанию указан
`erp-restore-api-token`.

| `MECHEL_SOURCE` | Что запускается |
|---|---|
| `agent` (по умолчанию) | `C:\OneScript_2\api\ПроверитьАПИ.os`, библиотека из `C:\OneScript_2\lib\mechel2`. Подходит для джобы с текстом Jenkinsfile |
| `checkout` | `НоваяАвтоматизация\Скрипты\Примеры\ПроверитьАПИ.os` и библиотека из той же копии исходников. Подходит для Pipeline script from SCM |

Размещение файлов и чтение лога описаны в [инструкции](../Библиотека/mechel/docs/ПРОВЕРКА.md).

Планируемые параметры:

- База-источник и база-приёмник копии.
- Необязательная Git-ветка для сборки основной конфигурации и расширения Mechel.
- Имя дополнительного расширения и сетевой путь `\\сервер\ресурс\файл.cfe`.
- Параметры монопольного обновления и настройки универсального пользователя.
- Jenkins credentials для API-токена и других нужных учётных данных.
- Уровень логирования и выбор дополнительных проверок.

Параметры относятся к будущему универсальному пайплайну.
