# Подготовить базу в Jenkins

Первый этап универсальной джобы выполняет восстановление существующей ИБ
через оркестратор. Сначала запустите эмуляцию на тестовом приёмнике.

1. Скопируйте [ВосстановитьИБ.os](../Скрипты/ПодготовкаИБ/ВосстановитьИБ.os)
   в `C:\OneScript_2\api` на агенте с OneScript 2.1 и установленной `mechel2 2.0.2`.
2. Создайте джобу Pipeline и укажите [ПодготовитьБазу.Jenkinsfile](ПодготовитьБазу.Jenkinsfile).
   Подойдёт текст Jenkinsfile или Pipeline script from SCM. В обоих случаях
   исполняется файл с агента, его путь виден в логе.
3. В `TOKEN` выберите Secret Text `erp-restore-api-token`. При первом прогоне
   оставьте `RESTORE_MODE=test` и заполните `SOURCE_INFOBASE` и `TARGET_INFOBASE`.
   Для однозначного выбора укажите `СЕРВЕР:ПОРТ|ИмяИБ`.

| Параметр | Что делает |
|---|---|
| `RESTORE_MODE=test` | Эмуляция API `test=1`. Согласно контракту занимает около пяти минут |
| `RESTORE_MODE=restore` | Реальное восстановление `test=0`. Содержимое приёмника заменяется копией источника |
| `RESTORE_MODE=wait` | Опрос существующей заявки. Нужен `RESTORE_GUID` |
| `MAKE_COPY` | По умолчанию используется доступная копия. Установите флаг для новой копии источника |
| `RESTORE_USER` / `RESTORE_OSNAME` | Необязательная настройка доступа существующего пользователя ИБ. Для ОС-учётной записи нужно имя пользователя ИБ. Оркестратор может сбросить пароль указанного пользователя |
| `WAIT_TIMEOUT_MINUTES` | Сколько ждать результата. По умолчанию 120 минут, опрос раз в минуту |

После отправки заявки GUID появится в консоли и описании сборки. По завершении
джобы его можно скачать из артефакта `restore-guid.txt`. Статус `0` завершает
джобу успешно, `-1` завершает её ошибкой, `1` и `2` продолжают ожидание.
Таймаут Jenkins или OneScript не отменяет заявку оркестратора.
[Как Jenkins хранит артефакты](https://www.jenkins.io/doc/pipeline/steps/core/#archiveartifacts-archive-the-artifacts).

При остановке Jenkins запустите `wait` с сохранённым GUID. Если ответ на
создание заявки потерян до получения GUID, найдите заявку в оркестраторе
по комментарию `Jenkins: job=<имя> #<номер>`. Маркер `.pending` удерживает
повторную отправку из того же каталога сборки.

Блокировками при восстановлении управляет оркестратор. Следующий этап —
сборка CF/CFE для выбранной ветки. Для применения к ИБ нужен способ закрыть
и сеансы, и соединения в окне монопольного обновления.

Локальная проверка из папки `НоваяАвтоматизация` использует временный
HTTP-сервер и вымышленные ИБ.

```powershell
python -B '.\Скрипты\ПодготовкаИБ\tests\test_restore.py' --oscript 'C:\OneScript_2\bin\oscript.exe'
```
