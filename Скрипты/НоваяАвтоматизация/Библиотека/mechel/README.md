# mechel2 2.0.2

Клиент API оркестратора «1С:Администрирование и эксплуатация» и общие средства
Jenkins-скриптов. Требуется **OneScript 2.1.0+**.
Для будущих операций с ИБ целевая платформа — **1С 8.3.27.2342**.

## Подключение

Для работы только с API используйте каталог `api`. Путь задаётся относительно
самого `.os`-файла. Для файла `НоваяАвтоматизация/Скрипты/МойСкрипт.os`:

```bsl
#Использовать "../Библиотека/mechel/api"
```

Для скрипта в `C:\OneScript_2\api` используйте `#Использовать "../lib/mechel2/api"`.
Оба входа API используют встроенные средства OneScript.

Для кода, которому одновременно нужны старый `ОбщийМодуль` и новый клиент,
подключайте `#Использовать mechel2` или корень `../Библиотека/mechel`.
Полный вход требует прежние пакеты `json`, `v8runner`, `asserts`, `fs`, `oint`.
Исходник `ОбщийМодуль.os` взят из mechel 1.1.2 побайтово. Старые скрипты
могут продолжать использовать `#Использовать mechel`. У нового пакета имя
`mechel2`, чтобы оба пакета могли стоять рядом.

При необходимости сборки пакета через установленный OPM:

```powershell
opm build .
```

Установка на агенте и расположение скрипта описаны в [ПРОВЕРКА.md](docs/ПРОВЕРКА.md).

## Быстрый пример

```bsl
#Использовать "../Библиотека/mechel/api"

Лог = Новый ЛогМечел("ERP", "INFO");
Клиент = Новый АПИКлиент("https://ukm-web/ad/IT/IT_TechAdmin/hs/", Лог);
Клиент.УстановитьТокен(
    ПомощникПайплайна.ОбязательнаяПеременнаяСреды("MECHEL_API_TOKEN"));

// Только чтение, сама блокировка не меняется.
Блокировка = Клиент.ПолучитьБлокировку("СЕРВЕР:ПОРТ|ТЕСТОВАЯ_БАЗА");
Лог.Информация("Параметры блокировки прочитаны");
```

По умолчанию HTTP использует учётную запись процесса ОС — на Jenkins это
учётная запись агента. API-токен — значение секрета, полученное из credentials,
а не ID credentials `erp-restore-api-token`.

Выберите Secret Text в параметре `TOKEN` Jenkins. Pipeline привязывает
выбранный секрет через Credentials Binding:

```groovy
withCredentials([string(credentialsId: params.TOKEN, variable: 'MECHEL_API_TOKEN')]) {
    bat '@chcp 65001 >nul\n@"C:\\OneScript_2\\bin\\oscript.exe" ".\\Скрипты\\МойСкрипт.os"'
}
```

Путь к скрипту и OneScript подставляется под размещение на вашем агенте.
Значение `MECHEL_API_TOKEN` библиотека передаёт защищённым методам: для GET
это URL-параметр `token`, для POST — поле `token` в JSON. Используйте HTTPS.
Клиент пишет в лог имя метода без параметров. Если веб-сервер или прокси
записывает query, настройте маскирование `token` на его стороне.

## Единые правила

- Обычный метод возвращает поле `result`, сохраняя его тип. Объекты JSON
  читаются в `Соответствие`, массивы — в `Массив`.
- При ошибке HTTP, некорректном JSON или коде ошибки API клиент вызывает
  исключение. Коды успеха — `0`, `"00.00"` и `"0"`. Для `GetInfobaseBlock`
  поддерживается прежний вариант `"00:00"`.
- `ПолучитьСтатусВосстановления` возвращает описанную структуру статуса;
  `ОжидатьЗавершенияВосстановления` завершает ожидание только на `result=0`,
  вызывает исключение на `-1` и продолжает ждать на `1` и `2`.
- Повторных отправок запросов нет. После сетевого сбоя изменяющей операции
  её результат может быть неизвестен. Таймаут ожидания не отменяет заявку.
- В логах нет тел запросов, тел ответов и полного URL с query. Токен и
  пароль маскируются в сообщениях библиотеки. Полученные данные вызывающий
  скрипт логирует осознанно, без вывода секретов.

## Состав и документация

| Компонент | Назначение |
|---|---|
| `АПИКлиент` | 19 адресов API, снятие блокировки и ожидание восстановления |
| `ЛогМечел` | Консоль, необязательный UTF-8-файл, уровни, маскирование секретов |
| `АПИСлужебный` | JSON, коды, ISO-даты, query, разбор адреса, статусы |
| `ПомощникПайплайна` | Переменные среды, комментарии Jenkins, проверка UNC-пути |
| `ДиагностикаМечел` | Путь скрипта, версия и путь библиотеки, чтение агентов и блокировки |
| `ОбщийМодуль` | Совместимость со скриптами mechel 1.1.2 |

## Автономные проверки

Из каталога библиотеки:

```powershell
oscript '.\tests\ТестыБиблиотеки.os'
```

Тесты используют заглушку транспорта и не обращаются к рабочему оркестратору.
Дополнительный тест реального HTTP с Python и сервером только на `127.0.0.1`:

```powershell
python -B '.\tests\http_mock.py' --oscript 'C:\OneScript_2\bin\oscript.exe'
```

Наличие локально пройденных тестов не подтверждает доменную авторизацию,
права API-токена и реальные операции на рабочем сервере.
