# Справочник mechel 2.0.0

Описаны все публичные процедуры и функции. Внутренние функции классов
не являются интерфейсом для вызывающих скриптов.

## Общие правила

`Клиент` в примерах — `АПИКлиент`, `Лог` — `ЛогМечел`, `База` — строка
`СЕРВЕР:ПОРТ|ИмяИБ` либо однозначное имя ИБ. Непустые строки обязательны,
если в сигнатуре не указано значение по умолчанию.

Обычный метод возвращает поле `result` без обёртки. Объект JSON читается в
`Соответствие` (`Данные["поле"]`), массив — в `Массив`. Схема объектов результата
не переименовывается. Любая ошибка HTTP, JSON, протокола или код ошибки API —
исключение. Специальная структура статуса восстановления описана ниже.

Параметры методов — `Структура` или `Соответствие` с точными именами полей API.
Неизвестное имя отклоняется; `Неопределено` пропускается; исходная коллекция
не меняется. Флаги: `Булево`, числа `0/1`, строки `true/false`, `истина/ложь`,
`да/нет`, `1/0` без учёта регистра. Опечатка — исключение, а не молчаливое `Ложь`.

## Создание и настройка

`АПИКлиент(Адрес = "https://ukm-web/ad/IT/IT_TechAdmin/hs/", Журнал = Неопределено, ТестовыйТранспорт = Неопределено)`.
Адрес — общий корень до `Objects1C`/`loading1c`, схема HTTP/HTTPS, порт можно
включить в имя сервера. Конечный слэш необязателен. Query, fragment и credentials
в URL не допускаются. Имя сервера без точки допустимо. Конструктор не подключается.

`Журнал` — экземпляр `ЛогМечел`; по умолчанию `mechel.api` с INFO.
Третий аргумент заменяет HTTP только для тестов, его интерфейс приведён в конце.
HTTP использует учётную запись ОС; таймаут одного запроса по умолчанию 120 секунд.

```bsl
Лог = Новый ЛогМечел("ERP", "INFO");
Клиент = Новый АПИКлиент("https://ukm-web/ad/IT/IT_TechAdmin/hs/", Лог);
```

| Процедура | Параметры и назначение | Пример |
|---|---|---|
| `УстановитьТокен(Значение)` | Строка со значением Jenkins-секрета, не ID credentials. `""` очищает токен | `Клиент.УстановитьТокен(ПомощникПайплайна.ОбязательнаяПеременнаяСреды("MECHEL_API_TOKEN"));` |
| `УстановитьАутентификацию(Пользователь = "", ПарольПользователя = "", ИспользоватьАутентификациюОС = Истина)` | Строки логина/пароля; при учётной записи ОС они должны быть пустыми. Для явной учётной записи третий аргумент — `Ложь`. Вызов без аргументов возвращает авторизацию ОС | `Клиент.УстановитьАутентификацию("DOMAIN\svc", ПарольИзСреды, Ложь);` |
| `УстановитьТаймаут(Секунды)` | Положительное целое число секунд одного HTTP-запроса; общий срок ожидания восстановления задаётся отдельно | `Клиент.УстановитьТаймаут(180);` |

Процедуры ничего не возвращают. Токен и пароль автоматически регистрируются
для маскирования в журнале; публичных свойств для чтения секретов нет.

## Чтение без API-токена

HTTP-аутентификация всё равно нужна. Все функции возвращают `result`.

| Функция | Назначение и параметры | Пример |
|---|---|---|
| `ПолучитьАгентов()` | Список агентов; без параметров | `Агенты = Клиент.ПолучитьАгентов();` |
| `ПолучитьКластеры(Агент = "")` | Список кластеров; необязательная строка `agent` | `Кластеры = Клиент.ПолучитьКластеры("СЕРВЕР:1540");` |
| `ПолучитьПроектныеКоманды()` | Проектные команды. GET принят по аналогии, уточнение в контракте API | `Команды = Клиент.ПолучитьПроектныеКоманды();` |
| `ПолучитьПроекты()` | Проекты. То же уточнение относительно GET | `Проекты = Клиент.ПолучитьПроекты();` |
| `ПолучитьИнфобазы(Агент = "", Кластер = "")` | Список ИБ с необязательными фильтрами `agent`/`cluster` | `Базы = Клиент.ПолучитьИнфобазы("", "СЕРВЕР:8541");` |
| `ПолучитьСеансыКластера(Кластер)` | Все сеансы; строка `cluster` обязательна. Имена полей элементов API.md не задаёт, фильтрации здесь нет | `Сеансы = Клиент.ПолучитьСеансыКластера("СЕРВЕР:8541");` |
| `ПолучитьПользователейБазы(Инфобаза, ВозвращатьИД = Истина, ТолькоОС = Ложь)` | ИБ и флаги `get_id`/`only_ad`, передаваемые в GET числами `1/0` | `Пользователи = Клиент.ПолучитьПользователейБазы(База, Истина, Ложь);` |

## Блокировка и обслуживание

Эти функции требуют токен и возвращают `result`:

| Функция | Назначение и параметры | Пример |
|---|---|---|
| `ПолучитьБлокировку(Инфобаза)` | Читает параметры запрета начала сеансов | `Блокировка = Клиент.ПолучитьБлокировку(База);` |
| `УстановитьБлокировку(Инфобаза, Параметры)` | Отправляет только заданные поля таблицы ниже. Уже открытые сеансы сама по себе не завершает | `Результат = Клиент.УстановитьБлокировку(База, Новый Структура("SessionsLockEnabled", Истина));` |
| `СнятьБлокировку(Инфобаза, СнятьБлокировкуРегламентныхЗаданий = Истина, Комментарий = "")` | Отправляет `SessionsLockEnabled=Ложь`. При втором аргументе `Истина` также `LockScheduledJobs=Ложь`; при `Ложь` регзадания не меняет. Прочие поля не перезаписывает | `Результат = Клиент.СнятьБлокировку(База, Истина, "Jenkins: завершено");` |
| `ПолучитьОбслуживание(Инфобаза)` | Читает отдельную блокировку обслуживания ИБ | `Обслуживание = Клиент.ПолучитьОбслуживание(База);` |
| `УстановитьОбслуживание(Инфобаза, Параметры)` | Изменяет поля блокировки обслуживания из таблицы ниже | `Результат = Клиент.УстановитьОбслуживание(База, Новый Структура("MaintenanceDisabled", Истина));` |

Все поля параметров необязательны; передавайте нужные изменения явно.

| Для `УстановитьБлокировку` | Тип и назначение |
|---|---|
| `SessionsLockEnabled` | Флаг запрета начала сеансов; JSON boolean |
| `LockBeginTime`, `LockEndTime` | Даты начала и окончания: `Дата` либо строка `yyyy-MM-ddTHH:mm:ss` |
| `SessionStartPermissionCode` | Строка кода разрешения входа, будущий `/UC` |
| `LockMessage` | Строка сообщения пользователю |
| `LockParameter` | Строка параметра блокировки |
| `LockScheduledJobs` | Флаг запрета регламентных заданий; JSON boolean |
| `comment` | Строка максимум 100 символов |

| Для `УстановитьОбслуживание` | Тип и назначение |
|---|---|
| `MaintenanceDisabled` | Флаг блокировки обслуживания |
| `MaintenanceDisabledDate` | Срок включительно: `Дата` либо ISO-строка без зоны |
| `MaintenanceDisabledNote` | Строка обоснования |
| `comment` | Строка максимум 100 символов |

Время отправляется без `Z` и автоматического пересчёта часового пояса.
Пример блокировки по образцу рабочего Jenkins-скрипта:

```bsl
Параметры = Новый Структура;
Параметры.Вставить("SessionsLockEnabled", Истина);
Параметры.Вставить("LockBeginTime", ТекущаяДата());
Параметры.Вставить("LockEndTime", ТекущаяДата() + 3 * 60 * 60);
Параметры.Вставить("SessionStartPermissionCode", КодРазрешенияИзСреды);
Параметры.Вставить("LockScheduledJobs", Истина);
Параметры.Вставить("LockMessage", "Установка обновлений");
Параметры.Вставить("comment", ПомощникПайплайна.КомментарийJenkins("erp-update", 42));
Результат = Клиент.УстановитьБлокировку(База, Параметры);
```

## Сеансы, процессы и кэш

Все функции требуют токен, возвращают `result`; комментарий — строка до 100 символов.

| Функция | Параметры и поведение | Пример |
|---|---|---|
| `ЗавершитьСеанс(Инфобаза, НомерСеанса, ТаймаутУдаления = 30, Комментарий = "")` | Номер и таймаут — положительные целые числа, строка `"123"` отклоняется. Таймаут в секундах; HTTP ждёт не меньше него плюс 5 секунд. Код 12 остаётся ошибкой | `Результат = Клиент.ЗавершитьСеанс(База, 123, 30, "Jenkins: обновление");` |
| `ЗавершитьПроцесс(Кластер, ИДПроцесса, Комментарий = "")` | Непустые строки `cluster` и `process`. Выключает рабочий процесс кластера, не один пользовательский сеанс | `Результат = Клиент.ЗавершитьПроцесс("СЕРВЕР:8541", ИДПроцесса);` |
| `СброситьКэш(Инфобаза, Комментарий = "")` | По API сбрасывает сеансы и соединения, временно переименовывает ассоциированную БД. Самостоятельная операция, не вызывается автоматически | `Результат = Клиент.СброситьКэш(База, "Jenkins: сброс кэша");` |

`ЗавершитьСеансыБазы` пока не реализован: нужен живой ответ `GetSessions`
с подтверждёнными полями базы и номера сеанса.

## Восстановление

### ЗапуститьВосстановление(БазаИсточник, БазаПриемник, Параметры = Неопределено)

POST `loading1c/new`, токен обязателен. Первые аргументы — строки
`sourceinfobase` и `targetinfobase`, не пути к архивам.
Одинаковые строки источника и приёмника отклоняются локально.
Возвращает GUID-строку непосредственно из `result`.

| Поле параметров | Тип и назначение |
|---|---|
| `test` | Флаг числом `1/0`. `1` — эмуляция 300 секунд по API.md; `0` — реальная операция |
| `makecopy` | Флаг числом `1/0`: создать свежую копию источника |
| `osname` | Строка ОС-учётной записи для аутентификации обезличенного администратора |
| `comment` | Строка до 100 символов |
| `forcecreate` | Флаг числом `1/0`: создать отсутствующие ИБ/БД |
| `dbmstype` | При `forcecreate=1` обязателен: `MSSQLServer`, `PostgreSQL`, `IBMDB2`, `OracleDatabase` |
| `db` | При `forcecreate=1` обязателен: `ЭкземплярСУБД\|БазаДанных` |
| `description` | Строка описания создаваемой ИБ |
| `licenseenable` | Флаг числом `1/0`: разрешить выдачу лицензий при создании |

Все поля необязательны, кроме условно обязательных при `forcecreate=1`.
Непереданные поля используют значения сервера: в API.md отсутствие `test`
означает реальную операцию, отсутствие `makecopy` — `0`.
Полей `archive`, `base`, `user`, `osuser` в этом методе нет.

Пример **эмуляции**, без реального восстановления:

```bsl
Параметры = Новый Структура("test,makecopy,osname,comment", 1, 1,
    "DOMAIN\analyst", ПомощникПайплайна.КомментарийJenkins("erp-restore", 42, "Автор"));
ГУИД = Клиент.ЗапуститьВосстановление(
    "СЕРВЕР:ПОРТ|ИСТОЧНИК", "СЕРВЕР:ПОРТ|ТЕСТОВАЯ_БАЗА", Параметры);
Итог = Клиент.ОжидатьЗавершенияВосстановления(ГУИД, 7200, 60);
```

Для реального восстановления явно передайте `test=0` и проверьте направление
копирования. Если успешный ответ не содержит корректный GUID, заявка могла
быть создана; перед повторным запуском проверьте оркестратор.

### ПолучитьСтатусВосстановления(ГУИД)

GET `loading1c/status?guid=...`, токен в заголовке. Аргумент — UUID-строка.
Возвращает структуру:

| Поле | Тип и значение |
|---|---|
| `Код` | Число `result`: `0`, `-1`, `1`, `2` |
| `Описание` | Человекочитаемая строка |
| `Завершено` | `Истина` для `0` и `-1` |
| `Успех` | `Истина` только для `0` |
| `ДатаОбновления` | `update_date` как пришло с сервера; при отсутствии `""`. Часовой пояс не угадывается |

```bsl
Статус = Клиент.ПолучитьСтатусВосстановления(ГУИД);
Лог.Информация(Статус.Описание);
```

`-1` возвращается как неуспешный статус задачи. Ненулевой `code`,
транспортный сбой или неизвестный `result` вызывают исключение.

### ОжидатьЗавершенияВосстановления(ГУИД, ТаймаутСекунд = 7200, ИнтервалОпросаСекунд = 60)

Оба интервала — положительные целые числа **секунд**. Опрос сразу, затем паузы.
`0` возвращает структуру успеха, `-1` вызывает исключение; `1` и `2` продолжают
ожидание. HTTP-таймаут ограничен остатком общего срока.
В INFO выводится изменение статуса, в DEBUG — `update_date` опросов.
Превышение срока вызывает исключение; заявку на сервере это не отменяет.

```bsl
Итог = Клиент.ОжидатьЗавершенияВосстановления(ГУИД, 7200, 60);
```

## Генерация запуска

`СгенерироватьЗапуск(Инфобаза, ИмяПриложения, Пользователь, Комментарий = "")`:
GET `run1c/generate`, токен обязателен. Аргументы — непустые строки `infobase`,
`appname`, `user`; комментарий до 100 символов. Возвращает непустую строку
токена запуска, автоматически зарегистрированную для маскирования.

```bsl
ТокенЗапуска = Клиент.СгенерироватьЗапуск(База, "ИМЯ_ПРИЛОЖЕНИЯ", "ПОЛЬЗОВАТЕЛЬ_ИБ");
// Передать токен потребителю, не печатать в журнал.
```

Расхождение `user/osuser` внутри API.md отмечено в контракте. Реализация
следует таблице входных параметров, оба имени одновременно не отправляет.
До рабочего использования эту часть контракта нужно подтвердить.

## ЛогМечел

`ЛогМечел(ИмяКомпонента = "mechel", Уровень = "INFO", ПутьКФайлу = "")`.
Имя — строка префикса, уровень — `DEBUG/INFO/WARN/ERROR/OFF` без учёта регистра.
Необязательный файл дополняется в UTF-8; родительский каталог должен существовать.
Время локальное для агента. Формат:
`2026-11-18T10:30:00 [INFO] [ERP] Сообщение`.

| Процедура | Назначение и пример |
|---|---|
| `ДобавитьСекрет(Значение)` | Строка для маскирования, пустая игнорируется. `Лог.ДобавитьСекрет(КодРазрешенияИзСреды);` |
| `Отладка(Сообщение)` | DEBUG. `Лог.Отладка("Начало этапа");` |
| `Информация(Сообщение)` | INFO. `Лог.Информация("База подготовлена");` |
| `Предупреждение(Сообщение)` | WARN. `Лог.Предупреждение("Заявка приостановлена");` |
| `Ошибка(Сообщение)` | ERROR, сама по себе исключение не вызывает. `Лог.Ошибка("Этап не завершён");` |

Все процедуры ничего не возвращают. Маскируются зарегистрированные строки,
URL-кодированная и JSON-экранированная формы. Переводы строк заменяются пробелами.
Сбой записи файла даёт предупреждение в консоли и не меняет результат API.

```bsl
Лог = Новый ЛогМечел("ERP", "DEBUG", "C:\JenkinsLogs\erp.log");
Лог.ДобавитьСекрет(ПарольИзСреды);
Лог.Информация("Начало обновления");
```

## АПИСлужебный

Чистые функции без сети и изменения файлов.

| Функция | Параметры, результат и пример |
|---|---|
| `ЕстьПоле(Источник, ИмяПоля)` | Структура/соответствие, включая фиксированные → наличие ключа даже при пустом значении. Для другого источника `Ложь`. `Есть = АПИСлужебный.ЕстьПоле(Данные, "result");` |
| `ЗначениеПоля(Источник, ИмяПоля, ПоУмолчанию = Неопределено)` | Значение ключа либо умолчание при отсутствии. `Текст = АПИСлужебный.ЗначениеПоля(Данные, "description", "");` |
| `ВJSON(Данные)` | Значение → JSON-строка встроенными средствами. `Текст = АПИСлужебный.ВJSON(Новый Структура("flag", Истина));` |
| `ИзJSON(Текст)` | JSON-строка → значение, объекты в соответствия; BOM в начале допустим. Неверный JSON — исключение без исходного текста. `Данные = АПИСлужебный.ИзJSON("{""code"":0}");` |
| `КодУспеха(Код)` | `Истина` только для `0`, `"00.00"`, `"0"`; другие корректные коды `Ложь`, неверный формат — исключение. `Успех = АПИСлужебный.КодУспеха("00.00");` |
| `ВБулево(Значение)` | Строгое преобразование поддержанных флагов. `Включено = АПИСлужебный.ВБулево("true");` |
| `ISOДата(Значение)` | `Дата` или ISO-строка без зоны → `yyyy-MM-ddTHH:mm:ss`. Невозможная дата отклоняется. `Текст = АПИСлужебный.ISOДата(ТекущаяДата());` |
| `СтрокаПараметровЗапроса(Параметры)` | Структура/соответствие простых значений → query без `?`, с URL-кодированием. Булевы → `1/0`, числа — только целые; `Неопределено` пропускается. `Query = АПИСлужебный.СтрокаПараметровЗапроса(Новый Структура("infobase", База));` |
| `РазобратьАдрес(Адрес)` | URL-строка → структура `Сервер,Путь`, путь с конечным слэшем. `Адрес = АПИСлужебный.РазобратьАдрес("https://ukm-web/hs/");` |
| `СтатусВосстановления(Код, ДатаОбновления = "")` | Число `0/-1/1/2` → структура статуса, другой код — исключение. `Статус = АПИСлужебный.СтатусВосстановления(2);` |
| `СкрытьСекреты(Текст, Секреты)` | Текст и массив строк → текст с `***`. `Неопределено` вместо массива оставляет текст. `Текст = АПИСлужебный.СкрытьСекреты(Описание, МассивСекретов);` |

## ПомощникПайплайна

| Функция | Параметры, результат и пример |
|---|---|
| `ОбязательнаяПеременнаяСреды(Имя)` | Читает строку переменной среды. Пустое значение — исключение с именем переменной, без значения. `Токен = ПомощникПайплайна.ОбязательнаяПеременнаяСреды("MECHEL_API_TOKEN");` |
| `КомментарийJenkins(ИмяДжобы, НомерСборки, Автор = "")` | Имя — строка, номер — строка/число, автор — строка. Возвращает `Jenkins: job=... #... \| ...` до 100 символов без переводов строк. `Комментарий = ПомощникПайплайна.КомментарийJenkins("erp", 42, "Автор");` |
| `ПроверитьСетевойПутьРасширения(Путь)` | Обычный UNC-путь к `.cfe` → путь без внешних пробелов. Проверяет сервер/ресурс/файл, запрещает `..` и маски. Наличие файла и права не проверяет. `Путь = ПомощникПайплайна.ПроверитьСетевойПутьРасширения("\\server\share\Mechel.cfe");` |

## Обработка ошибок

Клиент записывает ошибку обмена в журнал и вызывает исключение. Верхний скрипт
добавляет контекст этапа и обеспечивает ненулевой код выхода:

```bsl
Попытка
    Итог = Клиент.ОжидатьЗавершенияВосстановления(ГУИД);
Исключение
    Лог.Ошибка(ОписаниеОшибки());
    ЗавершитьРаботу(1);
КонецПопытки;
```

Автоматической разблокировки или отмены восстановления в клиенте нет.
Этим управляет будущий сценарий и Jenkins `post` с учётом результата этапа.
Повторных отправок изменяющих запросов нет: при потере ответа операция могла
выполниться. Перед ручным повторением проверьте фактическое состояние.

## Тестовый транспорт

Третий аргумент конструктора должен предоставлять следующую функцию:

```bsl
Функция Отправить(Метод, Путь, Заголовки, Тело, Таймаут) Экспорт
    // Метод GET/POST, относительный URL с query, соответствие заголовков,
    // JSON-тело либо пустая строка, таймаут в секундах.
    Возврат Новый Структура("КодСостояния,Тело", 200,
        "{""code"":0,""description"":"""",""result"":[]}");
КонецФункции
```

Заглушка получает секреты как настоящий HTTP и должна быть доверенным тестовым
кодом. В производственном вызове третий аргумент конструктора не передают.
