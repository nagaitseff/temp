# Проверка mechel 2.0.1

## На Jenkins

Для проверки из checkout используйте
`НоваяАвтоматизация/Пайплайны/ПроверитьАПИ.Jenkinsfile`.
Укажите тестовую ИБ в `MECHEL_TEST_INFOBASE` и ID credentials в `TOKEN_CREDENTIAL_ID`.

Если оставляете свою джобу с `C:\OneScript_2\api\ПроверитьАПИ.os`,
обновите содержимое `C:\OneScript_2\lib\mechel2` из каталога новой библиотеки.
На агенте скрипт должен подключать эту копию через `#Использовать mechel2`.
В вашей джобе задайте имя базы через `withEnv`. Одноимённый `def` доступен только Groovy.

```groovy
withCredentials([string(credentialsId: params.TOKEN, variable: 'MECHEL_API_TOKEN')]) {
    withEnv(['MECHEL_TEST_INFOBASE=ИМЯ_ТЕСТОВОЙ_ИБ']) {
        bat '@chcp 65001 >nul\n@"C:\\OneScript_2\\bin\\oscript.exe" "C:\\OneScript_2\\api\\ПроверитьАПИ.os"'
    }
}
```

При успехе в логе будут обе строки.

```text
Чтение списка агентов выполнено
Чтение параметров блокировки выполнено
```

| Что в логе | Где проверять |
|---|---|
| `HTTP 401/403` | Доменная учётная запись Jenkins-агента и доступ к публикации |
| `API code=5` на `GetInfobaseBlock` | Загружена ли версия 2.0.1 из нужного каталога. В обращении к администратору достаточно имени метода и кода ошибки |
| `API code=6–8` | Значение Jenkins Secret text, срок действия токена и права на метод |
| Читается только список агентов | Передаётся ли `MECHEL_TEST_INFOBASE` в процесс OneScript |
| Ошибка идентификации базы | Имя ИБ и кластер. Для неоднозначных имён задайте `СЕРВЕР:ПОРТ\|ИмяИБ` |

После чтения проверьте эмуляцию `loading1c/new` с `test=1`, тестовым
приёмником и опросом `loading1c/status` раз в минуту.
Пример вызова и таблица статусов есть в [справочнике](СПРАВОЧНИК.md).

## Локально

Из каталога библиотеки, с OneScript 2.1:

```powershell
oscript '.\tests\ТестыБиблиотеки.os'
python -B '.\tests\http_mock.py' --oscript 'C:\OneScript_2\bin\oscript.exe'
```

Второй тест требует Python 3.10+. Он поднимает сервер на `127.0.0.1`
с вымышленным токеном и проверяет реальные запросы, в том числе
`GetInfobaseBlock` и запуск `ПроверитьАПИ.os` с переменными среды.
[Результаты последнего прогона](РЕЗУЛЬТАТ_ПРОВЕРОК.md).
