# Проверка mechel2 2.0.2

## Запуск на Jenkins

Джоба `ПроверитьАПИ.Jenkinsfile` имеет два режима.

| `MECHEL_SOURCE` | Как запускать |
|---|---|
| `agent` | Скопируйте `api`, `src`, `package-loader.os`, `lib.config` и `opm-metadata.xml` из `Библиотека\mechel` в `C:\OneScript_2\lib\mechel2`. Положите `Скрипты\Примеры\НаАгенте\ПроверитьАПИ.os` в `C:\OneScript_2\api` |
| `checkout` | Укажите Jenkinsfile в джобе Pipeline script from SCM. Джоба сделает checkout и запустит файл из `НоваяАвтоматизация\Скрипты\Примеры`. Поддерживается и структура `Скрипты\НоваяАвтоматизация` |

В обоих режимах заполните `MECHEL_TEST_INFOBASE` и выберите Secret Text
в параметре `TOKEN`. Jenkins передаст значение секрета в OneScript через
`MECHEL_API_TOKEN` во время `withCredentials`.
[Справка Jenkins по привязке credentials](https://www.jenkins.io/doc/pipeline/steps/credentials-binding/).

Пакет OPM `mechel2-2.0.2.ospx` использует отдельное имя `mechel2`.
В старых джобах, которые подключают пакет `mechel`, путь подключения остаётся прежним.

## Что должно быть в логе

```text
Режим agent. Скрипт C:\OneScript_2\api\ПроверитьАПИ.os.
Библиотека mechel2 2.0.2: C:\OneScript_2\lib\mechel2\src\Модули\ДиагностикаМечел.os
GET Objects1C/GetAgents
Чтение списка агентов выполнено
GET Objects1C/GetInfobaseBlock для ИМЯ_ТЕСТОВОЙ_ИБ
Чтение параметров блокировки выполнено
```

Джоба выполняет два запроса на чтение. Значение секрета в лог не выводится.

| Что в логе | Где проверять |
|---|---|
| Ошибка `withCredentials` до запуска скрипта | Выбранный `TOKEN`, тип Secret Text и доступность секрета для этой джобы |
| Нет строки `Библиотека mechel2 2.0.2` | Сопоставьте режим, путь фактически запущенного скрипта и каталог библиотеки |
| `HTTP 401/403` | Доменная учётная запись агента и доступ к HTTP-публикации |
| `API code=5` на `GetInfobaseBlock` | Сначала сверьте версию по логу. Для проверки на стороне оркестратора передайте админу имя метода, код и время запроса |
| `API code=6–8` | Значение Secret Text, срок действия токена и права на метод |
| `API code=9–10` на `GetInfobaseBlock` | Имя ИБ и кластер. Для неоднозначных имён задайте `СЕРВЕР:ПОРТ\|ИмяИБ` |

После чтения проверьте эмуляцию `loading1c/new` с `test=1` и тестовым
приёмником. Пример вызова и статусы описаны в [справочнике](СПРАВОЧНИК.md).

## Локально

Из каталога библиотеки:

```powershell
oscript '.\tests\ТестыБиблиотеки.os'
python -B '.\tests\http_mock.py' --oscript 'C:\OneScript_2\bin\oscript.exe'
```

Второй тест требует Python 3.10+. Он проверяет запросы на `127.0.0.1`
с вымышленным токеном и запускает обе версии `ПроверитьАПИ.os`.
[Результаты последнего прогона](РЕЗУЛЬТАТ_ПРОВЕРОК.md).
