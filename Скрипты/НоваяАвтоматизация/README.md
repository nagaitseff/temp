# Новая автоматизация 1С:ERP

Новая разработка находится только в этом каталоге. Старые библиотеки, скрипты,
пайплайны и исходный набросок `mechel_2.0` остаются отдельно.

```text
НоваяАвтоматизация/
├── Библиотека/
│   └── mechel/       — новый пакет mechel 2.0.0 для OneScript 2.1
│       ├── src/      — клиент API, логирование, общие помощники
│       ├── docs/     — справочник, контракт API, порядок проверки
│       └── tests/    — автономные проверки и локальный HTTP-тест
├── Пайплайны/        — место новых Jenkins-пайплайнов
└── Скрипты/          — место новых OneScript-скриптов и примеров
```

Первый этап — [библиотека](Библиотека/mechel/README.md), согласованная
с предоставленным описанием API оркестратора и рабочими примерами.
Проверка против рабочего оркестратора выполняется на рабочем стенде.

Следующие этапы — новые скрипты и универсальный пайплайн:
копирование ИБ → необязательная сборка CF/CFE из ветки → применение к базе →
установка или обновление дополнительного расширения по имени и UNC-пути →
монопольное обновление → настройка одного универсального пользователя.

Целевая среда: OneScript 2.1, платформа 1С 8.3.27.2342.
Платформа 1С не требуется для работы клиента HTTP API и автономных тестов.
