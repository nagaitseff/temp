# Новая автоматизация 1С:ERP

Новая разработка находится только в этом каталоге. Старые библиотеки, скрипты,
пайплайны и исходный набросок `mechel_2.0` остаются отдельно.

```text
НоваяАвтоматизация/
├── Библиотека/
│   └── mechel/       — пакет mechel2 2.0.2 для OneScript 2.1
│       ├── src/      — клиент API, логирование, общие помощники
│       ├── docs/     — справочник, контракт API, порядок проверки
│       └── tests/    — автономные проверки и локальный HTTP-тест
├── Пайплайны/        — место новых Jenkins-пайплайнов
└── Скрипты/          — место новых OneScript-скриптов и примеров
```

На рабочем агенте проверено чтение API оркестратора через
[mechel2 2.0.2](Библиотека/mechel/README.md). Первый этап нового пайплайна
создаёт заявку на восстановление ИБ и ждёт результата.
[Настройка и запуск](Пайплайны/ПодготовитьБазу.md).

Следующие этапы: сборка CF/CFE из выбранной ветки и применение к базе,
дополнительное расширение по имени и UNC-пути, монопольное обновление,
настройка универсального пользователя.

Целевая среда: OneScript 2.1, платформа 1С 8.3.27.2342.
Платформа 1С не требуется для работы клиента HTTP API и автономных тестов.
