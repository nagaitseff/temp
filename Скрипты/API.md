# Общая информация

HTTP-сервисы поддерживают приём параметров в следующем порядке поиска:

| **№** | **Передача параметров** | **Примечание** |
|---|---|---|
| 1 | В параметрах запроса |  |
| 2 | В теле запроса | В формате JSON |
| 3 | В заголовках запроса |  |

HTTP-сервисы всегда возвращают код состояния (ответа) **200**. Отличный от 200 код указывает на ошибки на web-сервере. HTTP-сервисы всегда возвращают следующий результат в формате **JSON**:

| **№** | **Параметр** | **Тип** | **Описание** |
|---|---|---|---|
| 1 | `code` | Число или Строка | Код ошибки в формате числа или строки формата DD.DD, зависит от вызываемого сервиса |
| 2 | `description` | Строка | Описание ошибки |
| 3 | `result` | Число, Строка, JSON | Результат, тип возвращаемого значения зависит от вызываемого сервиса |

Общие для всех HTTP-сервисов коды ошибок:

| **Число** | **Строка** | **Описание** |
|---|---|---|
| 0 | 00.00 | Без ошибок, только в этом случае возвращается результат |
| 1 | 00.01 | Внутренняя ошибка обработки параметров запроса |
| 2 | 00.02 | Внутренняя ошибка обработки тела запроса |
| 3 | 00.03 | Внутренняя ошибка обработки заголовков запроса |
| 4 | 00.04 | Не найдены параметры для выполнения заявки |
| 99 | XX.99 | Не обрабатываемая ошибка времени выполнения |

# Безопасная загрузка информационной базы 1С (/loading1c)

## Этапы выполнения безопасной загрузки информационной базы 1С

| **№** | **Шаг** | **Описание** |
|---|---|---|
| 1 | Регистрация заявки | Получение параметров, регистрация заявки, присвоение ГУИД |
| 2 | Проверка корректности переданных параметров | Поиск соответствий параметров элементам |
| 3 | Первичная проверка разрешений на выполнение операции | Для исключения недопустимых операций (например, перезапись продуктивных ИБ) |
| 4 | Проверка прав на выполнение операции | Проверка токена доступа, его полномочий |
| 5 | Ручное подтверждение операции | В сложных случаях требуется ручное подтверждение заявки администраторами |
| 6 | Проверка на возможность в данный момент обработать заявку | Для исключения пересечения с основным резервным копированием |
| 7 | Снятие копии | При необходимости снятия копии онлайн с указанной ИБ |
